# Aribas: final logo (Script signature)

Chosen on 2026-11-09. Lettering: **Pinyon Script** (free for commercial use, SIL Open Font License).
Colours: maroon `#6E0F1C`, gold `#B8894D` / light gold `#E3C48F`, blush pink `#F6CCD4`, cream `#F7F2EC`, brown `#231710`.

| Folder | Files | Use for |
|---|---|---|
| `logo/` | Full logo (name + thread & needle + "Handmade detailing"), transparent, 2338×1155, in maroon / gold / pink / white | Packaging, labels, invoices, posters, letterheads |
| `wordmark/` | Just the name "Aribas", transparent, 2068×749, same four colours | Small spaces: tags, stickers, watermark on photos |
| `social/` | 1080×1080 squares on maroon / cream / brown | Instagram, WhatsApp, Facebook profile picture |
| `icon/` | Script "A" on maroon, 1024×1024 (square and rounded), plus the A alone in pink | App icon, favicon source, small avatar |
| `site/` | Favicons, home-screen icons and the link-preview image, already copied into the website's `public/` folder | The website |

Use maroon or white on light backgrounds, gold or pink on dark ones.
