# Aribas logos

Logo options, pick one (or a pair) to finalise. `00-all-options.png` shows them all side by side.

Each option folder has five PNGs, 2000×1120:
- `on-cream` / `on-brown` / `on-maroon`: on a solid brand background
- `transparent-maroon`: no background, for light surfaces (paper, labels, white boxes)
- `transparent-gold`: no background, for dark surfaces

`0-favicon-a/` is the website's current tab icon (the "A" tile), 512 and 1024 px.

`logos-source.html` is the design source: open it in Chrome to see every version; the logos are drawn from it.

Fonts used (all free for commercial use, SIL Open Font License): Oswald, Pinyon Script, Instrument Serif,
Cormorant Garamond, Inter.
