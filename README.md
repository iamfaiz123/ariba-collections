# Aribas

Kurtis and suits for women, handmade detailing, est. 2023.

| Folder | What it is |
|---|---|
| [frontend/](frontend/) | The storefront (React + Vite), live at https://ariba-collections.onrender.com. See [frontend/README.md](frontend/README.md). |
| [backend/](backend/) | API: users (WhatsApp login, orders, receipts, returns, admin), products, cart, payments (Razorpay). See [backend/README.md](backend/README.md). |
| [logos/](logos/) | Brand logo files. |

`render.yaml` describes the Render deployment (the static site builds from `frontend/`).
